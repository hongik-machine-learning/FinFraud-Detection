# FinFraud-Detection

신용카드 거래 데이터의 **이상 거래(사기) 탐지** 프로젝트입니다.
전체 거래 중 사기 거래가 약 0.17%에 불과한 **극심한 클래스 불균형** 환경에서, 사기 거래를 얼마나 잘 잡아내는지(Recall)와 정상 거래를 사기로 오탐하지 않는지(Precision) 사이의 균형을 목표로 두 가지 모델(SVM, MLP)을 구현하고 비교했습니다.

---

## 문제 정의

- **데이터 규모**: 284,807건의 거래, 31개 피처
- **클래스 불균형**: 정상 거래가 절대다수이고 사기 거래는 극소수 (약 0.17%)
- **핵심 과제**: 단순 정확도(Accuracy)는 무의미한 환경 (전부 "정상"으로 예측해도 99.8% 정확도). 따라서 **Precision과 Recall**을 기준으로 모델을 평가하고, 두 지표 간의 trade-off를 분석하는 것을 목표로 함

---

## 접근 방법

### 공통 전처리
- `Class` 열의 결측치 확인 및 제거
- 입력(X) / 출력(Y) 분리
- Stratified Split으로 학습/테스트 분리 (불균형 비율을 학습·테스트셋에 동일하게 유지)
- 이미 스케일링이 완료된 데이터(`scaled.csv`)를 사용

### 모델 1 — SVM (`SVM.ipynb`)
- RBF 커널 기반 비선형 분류
- `class_weight='balanced'`로 클래스 불균형 보정
- PCA로 2차원 축소 후 **결정 경계(decision boundary) 시각화**를 통해 사기/정상 데이터의 분포와 경계를 직관적으로 확인

### 모델 2 — MLP (`mlp.ipynb`)
- Keras 기반 다층 퍼셉트론 (Dense → BatchNormalization → Dropout 구조)
- `compute_class_weight`로 계산한 클래스 가중치를 학습에 반영
- 사기 클래스에 약 289배의 가중치를 부여해 소수 클래스 학습을 강화

## 결과

| 모델 | Precision | Recall | 특징 |
|------|-----------|--------|------|
| SVM  | 0.70      | 0.51   | 오탐이 적고 정밀하지만, 놓치는 사기가 많음 |
| MLP  | 0.05      | 0.91   | 사기를 대부분 잡아내지만, 오탐이 많음 |

**해석**
- **SVM**은 "사기라고 판단한 것 중 실제 사기 비율(Precision)"이 높아, 오탐으로 인한 불필요한 조치를 줄이는 데 유리합니다.
- **MLP**는 "실제 사기 중 잡아낸 비율(Recall)"이 높아, 사기를 놓치지 않는 것이 최우선일 때 유리합니다.
- 두 모델의 결과는 **Precision-Recall trade-off**를 뚜렷하게 보여줍니다. 실제 서비스에서는 사기 1건을 놓쳤을 때의 손실과 정상 거래를 오탐했을 때의 비용을 비교해, 어느 지표를 우선할지에 따라 모델과 임계값(threshold)을 선택해야 합니다.

## 배운 점

- 불균형 데이터에서는 정확도(Accuracy)가 아니라 **Precision·Recall**을 기준으로 모델을 평가해야 함을 실제 데이터로 확인했습니다.
- 클래스 가중치 보정(`class_weight`)이 소수 클래스 탐지 성능에 미치는 영향을 SVM·MLP 두 방식으로 비교했습니다.
- 하나의 "정답 모델"이 아니라, **비즈니스 목적(오탐 최소화 vs 미탐 최소화)에 따라 모델과 임계값을 선택**하는 관점을 익혔습니다.
